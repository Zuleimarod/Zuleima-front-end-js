# TechStore – Pre-Entrega de Proyecto Front-End

Página web de una tienda de tecnología creada como pre-entrega del curso Front-End (Talento Tech).

## Propósito
Presentar productos, mostrar reseñas de clientes y ofrecer un formulario de contacto funcional.

## Contenido
- `index.html`: estructura semántica (`header`, `nav`, `main`, `section`, `footer`).
- `styles.css`: estilos básicos, Google Fonts (Poppins y Roboto), backgrounds (color y degradado), Flexbox en **Productos**, Grid en **Reseñas** y Media Queries en **Contacto**.
- Formulario de contacto (nombre, correo electrónico y mensaje) conectado a **Formspree**.

## Cómo usarlo
1. Abrí `index.html` en el navegador.
2. Para que el formulario funcione, creá un formulario en [formspree.io](https://formspree.io) y reemplazá `TU_ID` en el atributo `action` de `index.html`.

## Tecnologías
HTML5 · CSS3 · Flexbox · Grid · Media Queries · Google Fonts · Formspree
